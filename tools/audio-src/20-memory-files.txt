# 第 20 集　記憶體與檔案管理
> 對應講義 12.1～12.5：分頁位址轉換、虛擬記憶體、頁面置換、檔案系統與權限。
這一集是第十二章：記憶體與檔案管理。兩種計算題：分頁的位址轉換，和頁面置換。
[停 1]
先分清楚兩種位址。邏輯位址是程式自己看到的，每個行程都以為從零開始。實體位址是資料真正在 RAM 裡的位置。轉換由 CPU 裡的 MMU 自動做。
如果每個行程都要一整塊連續的記憶體，用久了會留下很多零碎空洞，叫外部碎片。
[停 2]
解法是分頁。邏輯記憶體切成固定大小的頁，實體記憶體切成一樣大的頁框。每一頁可以放進任何一個頁框，用分頁表記錄。
位址轉換四步驟：
一，頁碼等於邏輯位址除以頁大小的商。
二，位移等於餘數。
三，查分頁表，頁碼換成頁框號碼。
四，實體位址等於頁框號碼乘頁大小，再加位移。
例子：頁大小一千零二十四，邏輯位址三千。三千除以一千零二十四，商二餘九百五十二。查表第二頁在頁框七。實體位址等於七乘一千零二十四，加九百五十二，等於八千一百二十。
位移不變，只有頁碼換成頁框。頁大小是二的 d 次方時，位址右邊 d 個位元就是位移。
分頁沒有外部碎片，但最後一頁通常用不滿，叫內部碎片。
[停 2]
第二個觀念：虛擬記憶體。頁不必全部在 RAM 裡，不常用的可以放硬碟，要用時才載入。
存取的頁不在 RAM 裡，叫分頁錯誤。作業系統從硬碟把那一頁載入，再重新執行。這是正常機制，不是程式寫錯。
RAM 太小、程式太多，系統大部分時間都在搬頁，叫輾轉現象。電腦突然變得很卡，就是它。
[停 2]
第三個觀念：頁面置換。頁框滿了，要踢掉一頁。
FIFO，踢最早載入的。
LRU，踢最久沒用的。
OPT，踢未來最久才會再用到的。OPT 錯誤最少，但要知道未來，做不到，只拿來比較。
手算時畫表，一欄一欄記頁框內容。記住：一開始頁框是空的，前幾次填空頁框也算錯誤。
經典例子，二十個參考、三個頁框：FIFO 十五次，LRU 十二次，OPT 九次。
FIFO 有一個怪現象：頁框變多，錯誤反而變多，叫 Belady 異常。
[停 2]
第四個觀念：檔案系統。檔案用目錄組織成一棵樹。絕對路徑從根目錄寫起，相對路徑從目前位置寫起，點點代表上一層。
檔案權限：擁有者、同群組、其他人，各有讀、寫、執行三種。讀是四，寫是二，執行是一，相加成一個八進位數字。
r w x 是七，r 槓 x 是五，r 槓槓是四，合起來七五四。六四四是一般檔案最常見的權限。
[停 2]
快問快答。
Q: 頁大小一千零二十四，邏輯位址兩千五百，頁碼是多少？
A: 二。
Q: 位址轉換時，位移會改變嗎？
A: 不會，直接照抄。
Q: LRU 踢掉哪一頁？
A: 最久沒被用到的。
Q: 頁框變多、FIFO 錯誤反而變多，叫什麼？
A: Belady 異常。
Q: r w x、r 槓 x、槓槓槓，八進位是多少？
A: 七五零。
