# 第 15 集　電腦網路
> 對應講義 8.1～8.5：封包與分層、IP 位址與子網路、DNS 與網址、頻寬與下載時間。
這一集是第八章：電腦網路。資料怎麼在電腦之間旅行。
[停 1]
先分清楚兩個詞。網際網路 Internet，是全世界的網路接在一起的網路的網路，是基礎建設。全球資訊網 WWW，只是跑在它上面的一種服務，另外還有電子郵件、線上遊戲、視訊通話。
提供服務的叫伺服器，發出請求的叫客戶端。
[停 2]
第二個觀念：封包。傳一張照片，不是整個一次送，而是切成很多小塊，每塊寫上地址和編號，分頭上路，到了再組回來。每一塊叫一個封包。
這叫封包交換。中途由路由器看地址決定往哪轉。相對的是傳統電話的電路交換，通話期間獨占一條線。
[停 1]
第三個觀念：分層。由上到下四層。
應用層，程式之間說的話，像 HTTP 傳網頁、DNS 查名字。
傳輸層，確保封包到齊、順序正確，像 TCP。用埠號區分同一台電腦上的不同服務。
網路層，跨網路找路，就是 IP。
連結層，同一條線、同一個 Wi-Fi 裡的傳輸。
應用、傳輸、網路、連結。像寄包裹：信是應用層，有編號的信封是傳輸層，收件地址是網路層，卡車是連結層。
[停 2]
第四個觀念：IP 位址。IPv4 是三十二個位元，切成四段，每段八個位元，零到兩百五十五，用點隔開。像 {192.168.1.37|一九二 點 一六八 點 一 點 三七}。
每一段就是一個八位元的無號數。{192|一九二} 就是 {11000000|一一零零零零零零}。
IP 位址分兩部分：前面是網路部分，後面是主機部分，分界線由子網路遮罩決定。{255.255.255.0|二五五 點 二五五 點 二五五 點 零} 就是二十四個一加八個零，簡寫成斜線二十四。
要算網路位址，把 IP 和遮罩做 AND：AND 一保留，AND 零清零。{192.168.1.37|一九二 點 一六八 點 一 點 三七} 配斜線二十四，網路位址是 {192.168.1.0|一九二 點 一六八 點 一 點 零}。
主機部分有 h 個位元，可用主機數是二的 h 次方減二。減二是因為全零是網路位址，全一是廣播位址。斜線二十四，兩百五十六減二，兩百五十四台。
[停 2]
{192.168|一九二 點 一六八} 開頭、{10|一零} 開頭的是私有位址。{127.0.0.1|一二七 點 零 點 零 點 一} 是本機。
IPv4 只有約四十三億個位址，不夠用。IPv6 用一百二十八位元。
[停 1]
第五個觀念：DNS，網域名稱系統，把網域名稱翻成 IP 位址，像一本全球電話簿。
網址的結構：協定、主機、埠號、路徑。HTTPS 是 HTTP 加上加密，預設埠號四四三，HTTP 是八十。
[停 1]
最後是計算題最常見的陷阱：網路速度的單位是每秒幾個位元，小 b。檔案大小是位元組，大 B。差八倍。
一百 Mbps 的網路，每秒十二點五 MB，不是一百 MB。
下載時間等於檔案大小乘八，再除以速度。一點五 GB 的影片用一百 Mbps 下載，一百二十秒，兩分鐘。忘記乘八，會算成十五秒。
頻寬是水管的粗細，延遲是水管的長度。下載大檔看頻寬，打遊戲看延遲。
[停 2]
快問快答。
Q: TCP/IP 四層，由上到下？
A: 應用、傳輸、網路、連結。
Q: IPv4 位址幾個位元？
A: 三十二。
Q: 斜線二十四的子網路可以給幾台裝置？
A: 兩百五十四。
Q: 一百 Mbps 每秒傳幾 MB？
A: 十二點五。
[停 1]
