# 第 16 集　程式語言
> 對應講義 9.1～9.6：編譯與直譯、變數與型別、整數除法、三種流程、函式、二分搜尋。
這一集是第九章：程式語言。不教某一種語言，而是講所有語言共同的骨架。
[停 1]
第一個觀念：語言的三個層次。
機器語言，CPU 直接執行的零和一。
組合語言，把每條機器指令換成英文縮寫，一對一翻譯。
高階語言，像 Python、Java、C，一行可能對應幾十條機器指令。
[停 1]
高階語言要翻譯才能跑，兩種翻法。
編譯：先把整份原始碼一次翻成執行檔，之後直接跑執行檔。執行快，改一行就要重編。像整本書翻譯好出版。C、C++ 是編譯型。
直譯：一邊讀原始碼一邊執行。改完馬上能跑，執行比較慢。像現場口譯。Python、JavaScript 是直譯型。
Java 是混合型，先編譯成位元組碼，再由虛擬機器執行。
[停 2]
第二個觀念：變數與型別。變數是一個有名字的記憶體格子。程式裡的等號是指派，把右邊放進左邊，所以 n 等於 n 加一是合理的：把 n 加一再放回去。
型別決定格子放什麼、怎麼解讀，對應前面學過的表示法：整數用二補數，浮點數用 IEEE 七五四，字串用 UTF-8，布林就是一和零。
三十二位元的整數，最大值是二的三十一次方減一，再加一就溢位變成負數。
[停 1]
整數除法最常考。兩個整數相除，結果也是整數，小數直接捨去。十七除以五等於三，不是三點四。餘數用百分比符號拿：十七餘五等於二。
餘數常用來判斷奇偶：n 除以二餘零，就是偶數。
運算順序：先乘除取餘，後加減，有括號先算括號。
[停 2]
第三個觀念：三種流程。任何程式都只需要三種結構。
順序：一行做完做下一行。
選擇：if，條件成立做 A，否則做 B。
重複：while 或 for，條件成立就一直做。迴圈要有終止條件，否則就是無窮迴圈。
讀程式最重要的技巧是追蹤變數：一行一行跑，記下每個變數當時的值，不要用直覺猜。
[停 2]
第四個觀念：函式。一段有名字、可以重複呼叫的程式。傳進去的叫參數，算完給回來的叫回傳值。別人寫好的一堆函式打包起來，就是程式庫。
[停 1]
第五個觀念：演算法的好壞。在排好順序的資料裡找一筆。
線性搜尋，從頭一筆一筆看，最差要看 n 次。
二分搜尋，先看中間，太大往左、太小往右，每次砍一半。最差只要 log 二 n 次。一千筆最多十次，一百萬筆最多二十次。
好的演算法比快的電腦更重要。
[停 2]
快問快答。
Q: 編譯和直譯，哪一個執行比較快？
A: 編譯。
Q: 整數運算，二十三除以四是多少？
A: 五。
Q: 二十三餘四呢？
A: 三。
Q: 三種流程結構？
A: 順序、選擇、重複。
Q: 四千零九十六筆排好的資料，二分搜尋最多比幾次？
A: 十二次。
[停 1]
