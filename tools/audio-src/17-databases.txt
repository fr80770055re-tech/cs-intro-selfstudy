# 第 17 集　資料庫
> 對應講義 10.1～10.5：資料表、主鍵與外來鍵、正規化、SQL、交易與 ACID、索引。
這一集是第十章：資料庫。資料要有地方放、放得有條理、很多人同時用也不會亂。
[停 1]
資料庫是一組有組織、互相關聯的資料，由資料庫管理系統，DBMS，統一管理。常見的有 MySQL、PostgreSQL、SQLite。
順便分清楚：資料是原始的事實，像八十五。資訊是處理過、有意義的結果，像小明數學八十五分，比平均高七分。
[停 2]
第二個觀念：關聯式模型。所有資料都放在二維表格裡。
每一列是一筆紀錄，像一個學生。每一欄是一個欄位，像姓名、成績。
主鍵：能唯一辨識每一列的欄位，不能重複、不能空白。學生表用學號，不用姓名，因為姓名可能同名。
外來鍵：一張表裡存著另一張表主鍵的欄位，用來建立關聯。學生表的系所代碼，指向系所表的主鍵。
[停 1]
一個系有很多學生，每個學生只屬於一個系，這叫一對多，用外來鍵表示。多對多，例如學生選課，要多一張中間表。
系所名稱只在系所表存一次，學生表只存代碼。不重複存同一件事，叫正規化。
[停 2]
第三個觀念：SQL，對資料庫下命令的語言。你說要什麼，不說怎麼找。
SELECT 選哪幾欄，FROM 從哪張表，WHERE 留下符合條件的列，ORDER BY 排序，加 DESC 是由大到小。
COUNT 數幾列，AVG 平均，MAX 最大，MIN 最小，SUM 總和。
跨表查詢用 JOIN，把外來鍵和主鍵對起來。
新增、讀取、更新、刪除，合稱 CRUD，對應 INSERT、SELECT、UPDATE、DELETE。
UPDATE 和 DELETE 忘了寫 WHERE，會改到或刪掉整張表。
[停 2]
第四個觀念：交易。轉帳要從 A 扣錢、給 B 加錢，兩步要嘛全做完，要嘛全部沒發生。
可靠的交易有四個性質，簡稱 ACID：
原子性，全做或全不做。
一致性，做完之後資料仍符合規則。
隔離性，同時進行的交易互不干擾。
持久性，說完成就不會丟。
[停 1]
最後兩個名詞。索引，像書後面的索引，另外建一份排好的對照表，查詢可以用二分搜尋，代價是占空間。
NoSQL，用在資料量大、結構常變的場合，像把資料存成 JSON 文件。
[停 2]
快問快答。
Q: 主鍵有哪兩個條件？
A: 不能重複、不能空白。
Q: 外來鍵存的是什麼？
A: 另一張表的主鍵。
Q: SQL 裡篩選列的子句？
A: WHERE。
Q: ACID 的 A 是什麼？
A: 原子性，全做或全不做。
[停 1]
